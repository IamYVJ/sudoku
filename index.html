How to Play

Fill the grid so every row, column and 3×3 box contains the digits 1 to 9 exactly once.

  • Tap a cell, then a number to place it.
  • Notes mode pencils in small candidates. Placing a digit clears it from the notes in the same row, column and box.
  • Clashing digits turn red.
  • Hint fixes a mistake first, otherwise fills the most constrained cell.
  • Every puzzle has exactly one solution. Easy to Hard never need guessing.
